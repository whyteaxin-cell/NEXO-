# NEXO v1

Premium social + messaging app foundation.

## Current
- Premium NEXO dark/neon visual identity
- Login / Create account UI
- Email or phone fields
- OTP entry point
- PWA manifest foundation

## Next production steps
1. Connect Firebase Authentication (phone OTP + email)
2. Add Firestore user profiles
3. Add Storage for photos/videos
4. Build Home, Reels, Stories, Chat and Notifications
5. Add moderation/privacy controls
6. Package the production Android app and prepare Play Store release

This first build is a UI foundation, not a production authentication system yet.
